# O Jogo das Decisões

Um simulador político e social que coloca à prova as ideias de esquerda, direita, centro ou de qualquer cidadão comum.

## 💡 Sobre o Projeto
A maioria de nós acha que tem a solução perfeita para o país. Mas nenhuma política é neutra ou grátis. Este simulador usa um motor profundo de dinâmica de sistemas e teoria dos jogos para testar as suas convicções.

O utilizador escolhe o país, a ideologia, o problema a resolver e as ferramentas. O simulador corre décadas para mostrar se o objetivo foi atingido, que efeitos colaterais surgiram (inflação, dívida, etc.) e, o mais importante, **quem ganhou e quem perdeu na sociedade**.

## 🚀 Como Jogar
1. Escolhe o país.
2. Escolhe a tua visão política (Esquerda, Direita, Centro) ou ajusta as ferramentas manualmente.
3. Escolhe o maior problema (Habitação, Dívida, Desemprego, etc.).
4. Vê a simulação e descobre o tribunal da realidade.
