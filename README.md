# 🏛️ Simulador de Sociedades — Governa um País

> **"Se fosses o líder de uma nação, que decisões tomarias? E se o teu país fosse a Alemanha? E o Brasil?"**

O **Simulador de Sociedades** é uma ferramenta interativa que te coloca no papel de um governante. Escolhe um dos 217 países disponíveis (com dados reais) ou cria o teu próprio país, define os sectores económicos e aplica políticas. Vê como a tua nação reage ao longo do tempo.

### 🚀 Acede à Aplicação
A aplicação está online, pronta a usar:
👉 **[CLIQUE AQUI PARA JOGAR AO SIMULADOR POLÍTICO](https://zimous12m-tech.github.io/simulador-politico/)**

### 🧠 O que vais encontrar:
- **217 Países:** Dados reais para simulares a economia de qualquer país do mundo.
- **Políticas de Impacto:** Aplica impostos, subsídios, reformas, e vê o efeito no PIB, na felicidade e na dívida.
- **Modo Livre:** Cria o teu próprio país com os dados que quiseres.
- **Feedback Imediato:** Gráficos e estatísticas que mostram o estado da tua nação.

### 🛠️ Tecnologias
- HTML5, CSS3 e JavaScript Vanilla.
- Design focado em Mobile-First e Dark Mode.
